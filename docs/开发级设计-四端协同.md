合法流转（仓库层强校验，非法动作直接抛 `IllegalStateException`）：
```
RAISED → COMMUNITY_RECEIVED（自动）
COMMUNITY_RECEIVED → DISPATCH_REQUESTED（紧急出警） | SELF_CLOSED（自行闭环）
DISPATCH_REQUESTED → URGENT（定时） | HOSPITAL_ACCEPTED（正常接警）
URGENT → URGENT | ESCALATED（第3次后） | HOSPITAL_ACCEPTED
ESCALATED → HOSPITAL_ACCEPTED | ESCALATED_UNANSWERED
HOSPITAL_ACCEPTED → HOSPITAL_DONE（医生填处置措施）
HOSPITAL_DONE → COMMUNITY_DONE → CLOSED          // 社区完成按钮仅此时可点
SELF_CLOSED / CLOSED / ESCALATED_UNANSWERED 为终态（后者允许改拨电话后手工关闭）
```

### 3.6 IncidentDao（核心查询，Flow 驱动跨账号自动刷新）
```kotlin
@Dao interface IncidentDao {
  @Insert suspend fun insert(i: IncidentEntity): Long
  @Update suspend fun update(i: IncidentEntity)
  @Query("SELECT * FROM incident WHERE id=:id") suspend fun getById(id: Long): IncidentEntity?
  @Query("SELECT * FROM incident WHERE id=:id") fun observeById(id: Long): Flow<IncidentEntity?>
  /** 社区网格员：本人负责 + 本社区未关闭事件 */
  @Query("SELECT * FROM incident WHERE communityStaffId=:staffId ORDER BY triggeredAt DESC")
  fun observeByCommunityStaff(staffId: String): Flow<List<IncidentEntity>>
  /** 医院：本院事件（在班视图在仓库层按排班二次过滤） */
  @Query("SELECT * FROM incident WHERE hospitalOrgId=:orgId AND status IN (:statuses) ORDER BY triggeredAt DESC")
  fun observeByHospital(orgId: String, statuses: List<String>): Flow<List<IncidentEntity>>
  /** 家属：本人名下老人的事件 */
  @Query("SELECT * FROM incident WHERE elderlyId IN (:elderlyIds) ORDER BY triggeredAt DESC")
  fun observeByFamily(elderlyIds: List<String>): Flow<List<IncidentEntity>>
  /** 大屏：社区维度聚合（仓库层拼成 8 栋状态） */
  @Query("SELECT * FROM incident WHERE communityOrgId=:orgId AND status NOT IN ('CLOSED','SELF_CLOSED')")
  fun observeActiveByCommunity(orgId: String): Flow<List<IncidentEntity>>
  @Query("SELECT * FROM incident WHERE hospitalOrgId=:orgId AND status NOT IN ('CLOSED','SELF_CLOSED')")
  fun observeActiveByHospital(orgId: String): Flow<List<IncidentEntity>>
  /** 先接先得 CAS：仅当尚无医生接警时占位成功（返回 1） */
  @Query("UPDATE incident SET hospitalDoctorId=:doctorId, status='HOSPITAL_ACCEPTED', hospitalAcceptedAt=:ts " +
         "WHERE id=:id AND hospitalDoctorId IS NULL")
  suspend fun casAccept(id: Long, doctorId: String, ts: Long): Int
  /** 调度器扫描：等待/加急中且未接警 */
  @Query("SELECT * FROM incident WHERE status IN ('DISPATCH_REQUESTED','URGENT') AND hospitalDoctorId IS NULL")
  suspend fun getWaiting(): List<IncidentEntity>

  @Insert suspend fun insertPenalty(p: DoctorPenaltyEntity): Long
  @Query("SELECT * FROM doctor_penalty WHERE doctorId=:doctorId ORDER BY createdAt DESC")
  fun observePenalties(doctorId: String): Flow<List<DoctorPenaltyEntity>>
  @Query("SELECT IFNULL(SUM(scoreDelta),0) FROM doctor_penalty WHERE doctorId=:id AND status='active'")
  suspend fun sumPenalty(id: String): Int
  @Query("SELECT COUNT(*) FROM doctor_penalty WHERE doctorId=:id AND status='active' AND penaltyType='missed_response'")
  suspend fun countMissed(id: String): Int
  @Query("UPDATE doctor_penalty SET status='revoked', revokedAt=:ts, revokeReason=:r WHERE id=:pid")
  suspend fun revokePenalty(pid: Long, ts: Long, r: String)
}
```

  apply_reason TEXT, reviewed_by TEXT, review_note TEXT,

  status TEXT DEFAULT 'active', created_at TEXT DEFAULT (datetime('now','localtime')) );

### 5.2 `tick()` 加急—升级—处罚伪代码（核心逻辑，严格按已确认参数）
```kotlin
suspend fun tick(now: Long) {
  incidentDao.getWaiting().forEach { inc ->
    val base = inc.dispatchRequestedAt ?: return@forEach
    val elapsed = now - base
    val shouldUrgent = elapsed >= IncidentConfig.URGENT_INTERVAL_MS * (inc.urgentCount + 1)
    if (inc.urgentCount < URGENT_MAX_TIMES && shouldUrgent) {            // 第 1/2/3 次加急
      update(inc.copy(urgentCount = inc.urgentCount+1, urgentLastAt = now, status = URGENT))
      pushWs("incident_urgent", inc.id)                                  // 在班医生强提醒
      return@forEach
    }
    if (inc.urgentCount >= URGENT_MAX_TIMES && inc.status != ESCALATED &&
        elapsed >= URGENT_INTERVAL_MS * URGENT_MAX_TIMES) {              // 第 3 次后升级
      escalate(inc, now)
    }
  }
}
private suspend fun escalate(inc: IncidentEntity, now: Long) {
  val onDuty = JSON.parse(inc.onDutyDoctorIds)            // 转警时在班名单
  // 1) 在班漏接处罚（onDuty 非空才罚；空=排班空缺，只给管理端记管理问题）
  if (onDuty.isNotEmpty()) onDuty.forEach { doc -> addPenalty(inc, doc, PenaltyType.MISSED, SCORE_MISSED, now) }
  // 2) 找下一排班人：当天后续最近班次 → 同院其他资质医生 → 院管理员
  val next = shiftDao.findNextOnDuty(inc.hospitalOrgId!!, now) ?: adminOf(inc.hospitalOrgId)
  // 3) 落库升级；15s 后 next 仍未接，再对 next 记 escalation_fault(-10)（下次 tick 判定）
  update(inc.copy(status = ESCALATED, escalatedAt = now, escalatedToDoctorId = next?.id,
                  missedDoctorIds = JSON.stringify(onDuty)))
  if (next == null) update(inc.copy(status = ESCALATED_UNANSWERED))
}
```
处罚等级在 `addPenalty` 内按该医生 active 漏接累计数自动定级：1→warning、≥3→notice、≥5→suspension（停班：`findNextOnDuty` 与在班过滤排除停班医生，需管理员撤销恢复）。

## 11. 实现注意事项（来自现有代码的坑，提前规避）
1. **Room 升级必须写 Migration 且列严格一致**：AppDatabase 无 destructive 升级兜底，实体列名/类型/NOT NULL/默认值/索引集合与 MIGRATION 不一致会直接崩溃（参考 MIGRATION_4_5、MIGRATION_6_7 注释里的真实教训）；新增 NOT NULL TEXT 列必须 `DEFAULT ''`。
2. **先接先得用 SQL CAS 而非先查后改**：`casAccept` 用一条 `UPDATE ... WHERE hospitalDoctorId IS NULL` 判断 rowsAffected，避免两医生并发同时接警。
3. **时间戳一律 Long 毫秒存 Room、ISO 字符串存云端**，展示层统一格式化；"完整时间链"靠 11 个可空字段，不要用状态推断时间。
4. **处罚前先判 onDuty 非空**：无人在班是排班管理问题，不罚医生，避免误伤；处罚可撤销、可申诉，全部写 audit_logs。
5. **临时授权最小化**：dispatch 开、CLOSED 收，未转警不开；家属端可见授权记录；复用现有 EmergencyService 破窗而非新造一套权限。
6. **跨账号"实时"在单机演示靠 Room Flow**：三账号共用 elderly_care.db，切前台即自动刷新，不要在 App 内依赖平台 WS；平台 WS 只服务 Web/真机，且必须先补 set_ws_manager 注入（现存断点）。
7. **多医院绑定**：社区点出警时若 ACTIVE 绑定 >1 家，弹窗选医院；仅 1 家直接出警；0 家时按钮置灰提示"未绑定合作医院"，允许改拨电话。
8. **大屏禁用真实地图**：8 栋/社区方块均为虚拟网格（可视化与 UI 一致），闪红用 Compose `infiniteTransition`，并提供暂停。
